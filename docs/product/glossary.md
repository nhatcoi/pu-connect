# Thuật ngữ

| Thuật ngữ | Giải thích |
|---|---|
| PUC | Tên viết tắt của PU Connect, cũng là tên miền puc.vnhat.dev |
| N7AI | Trợ lý học tập AI của PU Connect |
| Bảng tin | Danh sách bài viết ở trang chủ, gồm các tab Dành cho bạn, Đang theo dõi, Hỏi đáp |
| Dành cho bạn | Tab xếp hạng bài theo độ phù hợp với người xem |
| Lời giải được chấp nhận | Bình luận do tác giả câu hỏi chọn là câu trả lời đúng |
| Ẩn danh | Đăng bài hoặc bình luận không hiện danh tính công khai; hệ thống vẫn lưu tác giả thật |
| Cộng đồng | Nhóm chủ đề có chủ, điều hành viên và thành viên; có địa chỉ `/c/[slug]` |
| Nhóm học | Nhóm nhỏ gắn một môn học, có sĩ số tối đa, tuyển thành viên |
| Kho môn học | Tập tài liệu được phân loại theo môn học và loại tài liệu |
| Kho cá nhân | Danh sách tài liệu một người đã lưu hoặc tải riêng, tổ chức theo thư mục |
| Bộ sưu tập | Danh sách tài liệu do người dùng gom, có thể công khai |
| Bộ học | Flashcard hoặc quiz gồm nhiều mục |
| Ôn lặp lại ngắt quãng | Lịch ôn thẻ theo mức nhớ (thuật toán SM-2 rút gọn) |
| Chế độ học | Cách N7AI trả lời: hỏi đáp, giải thích, giải bài, lập kế hoạch, nghiên cứu, tạo quiz, flashcard |
| Capability | Bộ chỉ dẫn, công cụ và chính sách kết thúc gắn với một chế độ học |
| Tool | Công cụ N7AI gọi để tra cứu hoặc thao tác, ví dụ tìm tài liệu, đọc lịch |
| Connector | Kết nối ngoài cho N7AI: Google Drive, Calendar, Gmail, Forms, Sheets, Tasks, PU Connect, Semantic Scholar |
| MCP | Model Context Protocol, giao thức để N7AI gọi công cụ bên ngoài |
| RAG | Truy xuất tài liệu liên quan trước khi trả lời, dùng tìm kiếm từ khóa kết hợp vector |
| Lượt | Đơn vị hạn mức dùng N7AI mỗi ngày |
| Mức model | Nhanh, Cân bằng, Sâu; người dùng chọn mức chứ không chọn tên model thô |
| Provider | Cổng (gateway) cung cấp model AI, do admin cấu hình |
| Nhóm quyền | Tập quyền Admin Console gán cho người không phải admin |
| Hạn chế | Chế độ chỉ xem do xử phạt |
| Đề xuất | Yêu cầu thêm mục mới vào danh mục (trường, lĩnh vực, môn học) khi người dùng chọn "Khác" |
| Job (bot) | Lô bài đã sưu tầm giao cho một bot đăng theo lịch |
| ADR | Architecture Decision Record, bản ghi quyết định kiến trúc |
