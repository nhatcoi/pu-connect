# 👤 Domain 1: Identity & Profile (Định Danh & Hồ Sơ Sinh Viên)

> **Tài liệu đặc tả kiến trúc, mô hình dữ liệu, giao diện và tiến độ triển khai của Phân hệ 1 (Domain 1).**  
> *Đã loại bỏ hoàn toàn các yếu tố điểm thưởng/gamification và nhóm đồ án PBL rườm rà để tập trung tối đa vào cấu trúc hồ sơ sinh viên thực chất.*

---

## 🎯 1. Phạm Vi Nghiệp Vụ Cốt Lõi (Core Scope)

Theo bản thiết kế mạng xã hội sinh viên PU Connection, Domain 1 gồm 6 trụ cột:

1. **Student Profile**: Hồ sơ sinh viên chuẩn hóa (MSSV, Họ tên, Username, Email).
2. **Thông tin học tập**: Avatar, Bio, Chuyên ngành (`major`), Niên khóa (`academic_year`), Lớp sinh hoạt (`class_name`), Khoa/Viện (`faculty`).
3. **Kỹ năng & Sở thích**: Mảng kỹ năng chuyên môn (`skills`) và lĩnh vực quan tâm (`interests`).
4. **Xác thực sinh viên (University Verification)**: Kiểm tra email trường (`@phenikaa-uni.edu.vn`) và cấp huy hiệu Tích xanh xác thực chính chủ.
5. **Mạng lưới kết nối (Follow / Friend)**: Cơ chế theo dõi sinh viên/giảng viên, danh sách Followers & Following.
6. **Cài đặt quyền riêng tư (Privacy Settings)**: Cho phép sinh viên ẩn/hiện email, MSSV, lớp sinh hoạt và chế độ tài khoản riêng tư.

## 🗄️ 3. Thiết Kế Cơ Sở Dữ Liệu Hoàn Chỉnh Cho Domain 1

File migration: [`apps/api/src/database/domain1-upgrade.sql`](file:///Volumes/NVME_NHAT/Documents/Dev/Projects/PROJECT/pu-connector/apps/api/src/database/domain1-upgrade.sql)

```sql
-- 1. Bổ sung các trường chuyên sâu cho Domain 1 & Cây tổ chức học thuật Phenikaa
ALTER TABLE users ADD COLUMN IF NOT EXISTS school VARCHAR(100); -- Trường thành viên (vd: Trường CNTT Phenikaa)
ALTER TABLE users ADD COLUMN IF NOT EXISTS major VARCHAR(100); -- Chuyên ngành cụ thể (vd: Kỹ thuật phần mềm)
ALTER TABLE users ADD COLUMN IF NOT EXISTS class_name VARCHAR(50); -- Lớp sinh hoạt (vd: K17-KTPM1)
ALTER TABLE users ADD COLUMN IF NOT EXISTS is_verified BOOLEAN DEFAULT FALSE; -- Tích xanh xác thực trường
ALTER TABLE users ADD COLUMN IF NOT EXISTS verified_at TIMESTAMPTZ;
ALTER TABLE users ADD COLUMN IF NOT EXISTS privacy_settings JSONB DEFAULT '{
    "show_email": false,
    "show_student_id": true,
    "show_class": true,
    "is_private_profile": false
}'::jsonb;

-- 2. Chỉ mục tối ưu tìm kiếm theo sinh viên
CREATE INDEX IF NOT EXISTS idx_users_school ON users(school);
CREATE INDEX IF NOT EXISTS idx_users_major ON users(major);
CREATE INDEX IF NOT EXISTS idx_users_class ON users(class_name);
CREATE INDEX IF NOT EXISTS idx_users_is_verified ON users(is_verified);
```

## 🔌 4. Danh Sách API Endpoints Của Domain 1

| Phương thức | Endpoint | Mô tả chức năng |
| :--- | :--- | :--- |
| `GET` | `/api/auth/me` | Lấy thông tin phiên làm việc và hồ sơ cá nhân hiện tại. |
| `GET` | `/api/users/:username` | Lấy thông tin hồ sơ sinh viên (tự động lọc thông tin theo `privacy_settings` khi người ngoài xem). |
| `PATCH` | `/api/users/profile` | Chỉnh sửa hồ sơ cá nhân (Display Name, Bio, Chuyên ngành, Lớp sinh hoạt, Kỹ năng, Sở thích, Avatar). |
| `PATCH` | `/api/users/privacy` | Cập nhật cấu hình quyền riêng tư (Ẩn/hiện Email, MSSV, Lớp, Chế độ riêng tư). |
| `POST` | `/api/users/verify-university` | Kiểm tra và cấp Tích Xanh chính quy cho sinh viên Phenikaa. |
| `POST` | `/api/users/:id/follow` | Theo dõi / Bỏ theo dõi sinh viên/giảng viên khác. |
| `GET` | `/api/users/:id/followers` | Lấy danh sách những người đang theo dõi sinh viên này. |
| `GET` | `/api/users/:id/following` | Lấy danh sách những người mà sinh viên này đang theo dõi. |
